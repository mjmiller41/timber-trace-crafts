Foundations

Typography

Two self-hosted variable faces: Fraunces (serif display, headings) and Inter Tight (sans, body & UI). Headings run at weight 380–560, never bold; H1/H2 use tight -.015em tracking and Fraunces' opsz 144 / WONK 1 axes for editorial character. The earlier design plan paired Playfair Display + Montserrat — Fraunces + Inter Tight is the live replacement. This page approximates them with system serif/sans stacks (offline).

Foundations

Spacing & Radius

Spacing scale from the design plan's theme.json uses clamp() so section rhythm scales with the viewport. Containers: page max 1340px, reading column max 645px. Radius is deliberately minimal — the storefront runs square (radius 0) on buttons, cards, and inputs; only admin chrome and pills use small radii.

Components

Buttons

Three real button classes from app.css. All square, uppercase, letter-spaced .1em, Inter Tight 600. Solid buttons fade to 85% opacity on hover; outline buttons wash 5% (dark: 8%).

Form fields

The .form-field: 1px black border (square), Walnut placeholder, and a distinctive double focus ring (oak-sand halo + walnut outline).

Cards

Flat, shadowless. Depth comes from a Walnut hairline border, not elevation.

Care Guide

Navigation (storefront header)

Sticky, Oak Sand background, thin Walnut border-bottom. Fraunces wordmark, section-label links, minimal line icons, and the light/dark toggle.
